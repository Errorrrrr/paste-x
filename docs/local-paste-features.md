## 使用

运行 dist/local-library/PasteX.app。已有 PasteX 在运行时，先从旧版菜单退出，避免快捷键冲突。本次没有覆盖 /Applications 中的应用。

- 默认 ⌘⌥V 打开面板，直接输入或 ⌘F 搜索，左右箭头选择。
- Return、空格或双击粘贴；⇧Return 仅粘贴纯文本，历史中的原始格式不变。
- ⌘1–9 粘贴当前筛选结果中的对应项目。
- ⌘ 点击卡片或右键“选中 / 取消多选”，再点“合并粘贴”。使用当前列表顺序、换行分隔；没有文本表示的内容不能合并。
- “加入队列”按当前列表顺序加入选中项。“队列”菜单可以反转顺序、移除单项或清空。
- 每次在目标应用打开面板后按 ⌘Return，或选择队列菜单的“粘贴下一项”。成功发送粘贴命令后才移除队首；仅复制降级和失败都保留队首。队列是临时状态，不跨重启保存。
- 右键查看/编辑、收藏、指定分组或删除。按 Delete 删除当前项或多选项。拖动卡片可调序；右键也可“移到最前”。
- 工具栏“全部历史”菜单可切换收藏/分组或创建分组；右侧调节按钮打开“历史与隐私”，可重命名/移除分组。
- 移除分组会将里面的内容转为收藏，不删除内容。“清空未收藏历史”保留收藏和分组内容。
- 图片 OCR 自动在本机后台串行运行，识别结果进入搜索及详情。文本处理先预览，点击“保存”才更改历史；编辑内容保存为纯文本。

## 保存及隐私规则

正式应用显式使用 ~/Library/Application Support/PasteX/Library。依赖容器默认使用内存库，避免测试或嵌入使用时意外访问个人历史。

- 默认保留 1,000 条普通历史、30 天、500 MB；条数和天数设为 0 表示不限，容量仍有限制。
- 收藏或分组中的内容不自动清理，其体积也计入容量；收藏超出容量时，新的普通内容可能无法保留。
- 单次超过 50 MB 的剪贴板负载不采集。图片和其它格式按每个片段独立保存，清单引用不可变记录文件；清单提交前失败会回滚，重启时清理本格式的残留记录。
- 默认跳过 ConcealedType、TransientType、AutoGeneratedType 等敏感/临时标记，并预置常见密码管理器的 Bundle ID。未标记的密码不能保证识别，可排除整个来源应用。
- 暂停设置持久化；恢复时重置采集基线，不补录暂停期间最后一次复制。排除规则只影响后续采集，已有内容需自行删除。
- 来源应用取采集时前台应用，后台写入可能产生归属误差。
- 历史只存在本机，目录仅当前用户可访问，未另行加密。
- 文件仅保存 URL 引用，不备份文件本体。Quick Look 支持取决于系统及已安装扩展；文件失效会显示缺失状态。
- 无法识别或损坏的现有库保留原文件并停止写入，面板显示错误；不会静默覆盖。
