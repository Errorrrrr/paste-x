# PasteX v1.1.1

- 修复覆盖升级时，历史库设置缺少新增字段便导致整库读取失败的问题；已有设置值保留，缺少字段使用默认值。
- 记录缺失或数据损坏时继续保护原文件，不自动清空；避免读取中途失败后显示不完整历史。
- 读取错误显示具体文件、字段或系统错误代码。右键错误文字选择“复制完整错误信息”，可用于进一步定位；无需提供剪贴板正文。

120 项 Swift 测试通过，包括旧设置读取、继续写入、重启恢复、损坏库不覆盖及记录缺失保护。覆盖安装异常已用合成旧设置复现；尚未在用户另一台电脑上验证该修复。

支持 Apple Silicon Mac，macOS 14 或更新版本。安装包使用 ad-hoc 本机 QA 签名，未经 Apple Developer ID 签名或公证。升级前退出旧版，覆盖应用即可；不要删除历史目录。
