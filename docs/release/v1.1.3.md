# PasteX v1.1.3

- 新增菜单栏“检查更新…”：检查 GitHub 最新稳定版本，显示当前版本、可用的新版本或检查失败原因。
- 发现新版本后可打开 GitHub 发布页下载；只有包含适用安装包的发布版本才会提示升级。
- GitHub Actions 在版本标签推送或手动触发后执行完整测试、构建 Apple Silicon QA 安装包，并发布 ZIP 与 SHA-256 校验文件。
- 新版本先以草稿上传并核验安装包，再公开发布，避免检测到尚无安装包的版本；重跑旧版本不会将其设为最新版本。

支持 Apple Silicon Mac，macOS 14 或更新版本。本次提供 ad-hoc 签名的 QA 安装包，未经 Developer ID 签名或公证。检测更新不会自动下载或替换应用；请从发布页下载安装包，退出旧版后覆盖应用，保留现有历史目录。
