# PasteX v1.1.5

- 发布正式稳定版，安装包统一命名为 `PasteX-1.1.5-macos-arm64.zip`，移除 `qa-only` 后缀，并提供对应的 SHA-256 校验文件。
- GitHub Actions 发布工作流更名为 `Release`，执行完整测试、构建、上传与下载校验后公开发布。
- 默认构建使用标准包名；更新检测继续兼容标准包名和历史 QA 包名，旧版可以检测到此次更新。

支持 Apple Silicon Mac，macOS 14 或更新版本。此版本采用 ad-hoc 签名，未经 Developer ID 签名或公证；首次打开时可能需要在 macOS“隐私与安全性”中允许打开。

检测更新不会自动下载或替换应用；请从发布页下载安装包，退出旧版后覆盖应用，保留现有历史目录。
