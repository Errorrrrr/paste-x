# PasteX v1.1.4

- 新增菜单栏“检查更新…”：检查 GitHub 最新稳定版本，显示当前版本、可用的新版本或检查失败原因，支持中英文。
- 发现新版本后点击“下载更新…”打开 GitHub 发布页。只有已上传适用于当前 Mac 安装包的版本才会提示升级；重复点击合并请求，关闭窗口取消检测。
- GitHub Actions 执行完整测试、构建 Apple Silicon QA 安装包，并发布 ZIP 与 SHA-256 校验文件。新版本先以草稿上传和下载核验，再公开发布；重跑旧版本不会抢占最新版本。
- main 分支提交和 Pull Request 自动运行完整测试；失败时直接在检查结果中展示关键错误。
- 修复窗口位置测试的计时假设：等入场动画到达目标位置后再检查弹窗，避免较慢的 CI 将动画起始位置误记为最终位置。

v1.1.3 在测试阶段失败，没有发布安装包；此版本包含对应修复。支持 Apple Silicon Mac，macOS 14 或更新版本。本次提供 ad-hoc 签名的 QA 安装包，未经 Developer ID 签名或公证。

检测更新不会自动下载或替换应用；请从发布页下载安装包，退出旧版后覆盖应用，保留现有历史目录。GitHub 限流或网络不可用时，窗口会说明原因并允许重试。
