# PasteX v1.1.0

## 更新内容

- 本地保存剪贴板历史，支持容量与保留时间设置、收藏和分组。
- 全文、名称、来源应用、时间和类型筛选；图片文字在本机通过 OCR 识别并搜索。
- 多文件粘贴保留原始对象边界，支持纯文本粘贴、数字快捷键、多选合并和顺序粘贴队列。
- 内容详情与编辑、文件缩略图、富文本预览，以及 JSON 格式化、URL 编解码。
- 隐私过滤、应用排除、暂停记录和历史清理；不引入云同步或网络 OCR。
- 修复打开详情、设置和新建分组时底部主窗口上移的问题；补充关闭动画兜底，避免旧关闭任务影响重新打开的窗口。

## 下载与验证

- 支持 Apple Silicon Mac，macOS 14 或更新版本。
- 安装包使用 ad-hoc 本机 QA 签名，未经 Apple Developer ID 签名或公证，不等同于已公证发行包。首次打开可能需要 macOS 手动批准。
- 发布前 116 项 Swift 测试通过，包含真实 AppKit 窗口坐标、多文件系统剪贴板及本地 Vision OCR 验证。
- 弹窗修复后的人工界面复验因本机锁屏未完成；未遍历所有第三方应用的自动粘贴行为。
- 历史保存在本机，未额外加密；文件内容保存引用，不备份文件本体。升级前请退出正在运行的旧版。
