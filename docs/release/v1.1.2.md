# PasteX v1.1.2

- 修复旧版历史库清单无法读取的问题。识别 `itemIDs / pinboards / preferences` 结构，完整读取记录后迁移到当前格式。
- 迁移前备份旧清单为 `manifest.legacy-v1.json`，保留旧记录文件；将来源应用和可对应的历史、隐私设置带入新格式。
- 旧版收藏板非空、记录缺失或损坏时继续停止写入，避免覆盖原始数据。

已在 61 条、约 59 MB 的真实旧库副本上验证迁移、重启和新增记录；61 个旧记录文件均未改变。另增加合成旧库和旧收藏板的回归用例。本机 Command Line Tools 的 SwiftPM 与 SDK 不匹配，标准测试未能启动；核心和完整应用已直接编译，迁移路径已用直接编译的程序验证。

支持 Apple Silicon Mac，macOS 14 或更新版本。本次提供 ad-hoc 签名的 QA 安装包，未经 Developer ID 签名或公证。升级前退出旧版，覆盖应用即可；不要删除历史目录。旧版纯文本粘贴和批量分隔符设置保留在备份清单中，当前设置页没有对应项。
