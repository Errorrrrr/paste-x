# PasteX v1.1.6

[下载 macOS 安装版（DMG）](https://github.com/Errorrrrr/paste-x/releases/download/v1.1.6/PasteX-1.1.6-macos-arm64.dmg)

- 新增 macOS 拖拽安装包 `PasteX-1.1.6-macos-arm64.dmg`：双击打开后，将 `PasteX.app` 拖到 `Applications` 即可安装。
- GitHub Actions 自动构建并检查 DMG 和应用签名，上传安装包后重新下载并核验 SHA-256，成功后公开发布。
- 更新检测支持 DMG 安装包；继续提供 ZIP 及其校验文件，确保 v1.1.4、v1.1.5 用户仍能检测到本次更新。旧版用户也可从发布页选择 DMG 安装。

支持 Apple Silicon Mac，macOS 14 或更新版本。此版本采用 ad-hoc 签名，未经 Developer ID 签名或 Apple 公证；首次打开时可能需要在 macOS“隐私与安全性”中允许打开。

升级时，先从菜单栏退出旧版 PasteX，双击打开 DMG，将 `PasteX.app` 拖入 `Applications` 并确认替换。复制完成后弹出磁盘映像，再从“应用程序”打开 PasteX；已有剪贴板历史会保留。检测更新不会自动下载或替换应用。
